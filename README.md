# KOBUSHI BEER NIGHT 店舗ツール (kbn_clockwork)

## 概要

KOBUSHI BEER NIGHT 店舗で使用するフロントエンドツールを配信する公開リポジトリ。
GitHub Pages で配信される。

## 配信URL

- トップ: https://kobushimarketing-cloud.github.io/kbn_clockwork/
- 時間計算ツール: https://kobushimarketing-cloud.github.io/kbn_clockwork/time-calculator.html

## 非検索インデックス

robots.txt と HTML メタタグ(noindex)により、検索エンジンにインデックスされません。
URL を直接知っている人のみがアクセス可能です。

## 技術

- 素のHTML+CSS+JavaScript、外部依存ゼロ
- iPad Safari 対応、ホーム画面追加でアプリ感覚
- オフライン動作(Safariキャッシュ経由)
